# ManushyaM

Ayurvedic anti-hair-fall e-commerce store. Plan: [`PLAN.md`](PLAN.md) · Design spec: [`getdesign.md`](getdesign.md)

| Folder | What |
|---|---|
| `FE/` | React 19 + Vite + Tailwind storefront and admin panel |
| `BE/` | Express 5 + MongoDB (Mongoose) API |

## Run locally

```bash
docker compose up -d                 # MongoDB (replica set) + Mailpit inbox at http://localhost:8025

cd BE && cp .env.example .env        # fill in the three secrets (command in the file)
npm install && npm run seed && npm run dev   # API on http://localhost:5001  (GET /health; 5000 is taken by macOS AirPlay)

cd ../FE && npm install && npm run dev   # store on http://localhost:5173
```

`/styleguide` (dev only) shows every design token and component.

## Checks

```bash
cd BE && npm run lint && npm test    # API tests use an in-memory MongoDB replica set
cd FE && npm run lint && npm test && npm run build
```

CI (`.github/workflows/ci.yml`) runs the same checks plus `npm audit`, gitleaks and Semgrep on every push and PR.
